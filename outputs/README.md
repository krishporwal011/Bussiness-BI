# Generated outputs

The repository includes the top-10 count-ranked and lift-ranked pair tables, plus the rare-item impact table. The complete `python_pair_metrics.csv` is also included because it is a required analytical output; at approximately 54 MB it is intentionally the largest tracked file in the repository.

The raw workbook, normalized SQL staging extract, and cleaned transaction/presence extracts are not committed because they are reproducible, larger source/derived data artifacts. Download the UCI workbook and run the documented commands to regenerate them.
